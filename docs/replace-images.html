替换产品配图

官网配图都在仓库 docs/media/。用同名文件覆盖即可，不必改 HTML。推送到 main 后，GitHub Pages 一两分钟会更新。

1. 文件对照

文件出现位置建议拍什么
media/hero.png首屏大图最大化后的干净主界面，双栏、无弹窗、无录制控件
media/ui.png界面清爽列表 + 精美后缀图标 + 左侧盘符，可慢扫停留
media/copy.png拷贝引擎任务面板展开，能看到队列/进度
media/fav.png收藏夹顶栏分组展开（如 Acme / Nova）
media/split.png无限分栏左右或上下分栏，可带置顶/颜色
media/quick.png快捷栏选中文件后的浮动快捷操作条
media/preview.png预览Markdown 预览/编辑，不要录制手册原文
media/icon.png导航 Logo应用图标，建议 192×192 PNG

2. 规格

  • 格式：PNG 或把扩展名仍存成 .png（JPG 内容也可以，但文件名保持上表）
  • 官网按原图完整展示，不裁切。建议统一尺寸（例如 3840×2100），构图时把关键 UI 留在画面内
  • 内容：只露产品窗口，避开任务栏、录屏悬浮条、个人路径
  • 单张尽量 < 2.5 MB，全页才加载得快

3. 替换步骤

1. 全屏录或截：Win+Shift+S，或把视频导出一帧
2. 用画图 / Photoshop 裁成 16:9 或超宽（hero 可用超宽）
3. 覆盖 docs/media/ 里对应文件名（不要改名）
4. 提交并推送到 main：

git add docs/media/*.png
git commit -m "docs: update product screenshots"
git push origin main

网页代码不用动。若一定要换文件名，再改 docs/index.html 里对应的 src="media/....png"。

4. 可选：本机预览

cd docs
python -m http.server 8080
# 浏览器打开 http://localhost:8080
